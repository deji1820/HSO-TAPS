# HSO-TAP Database Backup & Setup Guide

This directory (`DATABASE/`) contains complete exported snapshots of the local **MongoDB** database for the **HSO-TAP (Health Services Office - Touch & Access Portal)** system, along with the **Supabase Real-time Cloud Table Schema** configuration.

---

## 📁 Database Files Overview

| File Name | Description |
| :--- | :--- |
| **`students.json`** | Master Student Profiles — Includes RFID Card UIDs, Student IDs, Names, Age, Sex, Guardian Contact Numbers, Programs, and Year Levels. |
| **`users.json`** | Admin & Medical Staff Accounts — Login credentials and role assignments for the Admin Portal. |
| **`queueentries.json`** | Kiosk Queue Records — Active and historical queue check-ins generated by student kiosk sessions. |
| **`vitalslogs.json`** | Measured Vitals Logs — Recorded body temperature, height, weight, and calculated BMI values. |
| **`consultationrecords.json`** | Clinical Consultation Records — Medical and dental visit logs linked to student EMR profiles. |
| **`counters.json`** | System Counter Trackers — Sequence counters used for generating daily queue numbers. |
| **`full_database_export.json`** | Combined Database Dump — Single JSON file containing all collections combined. |

## 🚀 How to Import / Restore MongoDB

### Option 1: Automated Import (Recommended)
You can automatically import all collections directly into your local MongoDB using the provided npm script in `packages/server`:

1. Ensure MongoDB is running locally (or Docker container `docker-compose up -d`).
2. Open terminal in the project directory:
   ```bash
   cd packages/server
   node scripts/importDatabase.js
   ```

---

### Option 2: Automated Seeding Script
To seed fresh student profiles programmatically without importing old logs:

```bash
cd packages/server

# Seed all 7 student profiles & RFID tags
node scripts/seedAllStudents.js

# Seed an Admin User
node scripts/seedAdmin.js "System Admin" admin@nufv.edu.ph password123
```

---

### Option 3: Manual Import via MongoDB CLI (`mongoimport`)
If using standard MongoDB command line utilities:

```bash
mongoimport --uri="mongodb://hsotap:changeme@127.0.0.1:27017/hsotap?authSource=admin" --collection=students --file=DATABASE/students.json --jsonArray
mongoimport --uri="mongodb://hsotap:changeme@127.0.0.1:27017/hsotap?authSource=admin" --collection=users --file=DATABASE/users.json --jsonArray
mongoimport --uri="mongodb://hsotap:changeme@127.0.0.1:27017/hsotap?authSource=admin" --collection=queueentries --file=DATABASE/queueentries.json --jsonArray
mongoimport --uri="mongodb://hsotap:changeme@127.0.0.1:27017/hsotap?authSource=admin" --collection=vitalslogs --file=DATABASE/vitalslogs.json --jsonArray
```

## ⚡ Supabase Setup & Real-Time Wireless Hardware Sync

### Role of Supabase in HSO-TAP
Supabase PostgreSQL & Real-time WebSocket Channels are used as the **wireless message broker** between the **ESP32 microcontroller hardware (`HSO-TAP.ino`)** and the **React Kiosk App (`kiosk-app`)**:

1. **RFID Tap**: ESP32 scans an RFID card $\rightarrow$ HTTP POSTs `{ rfid_uid, status: "tap_logged" }` to Supabase `kiosk_sessions`.
2. **Kiosk Realtime Listener**: Kiosk app receives the realtime `INSERT` event and immediately transitions to the **"Is this your profile?"** screen.
3. **Sensor Readings**: Sensors write `temp_c`, `height_m`, `weight_kg` $\rightarrow$ Kiosk app receives realtime `UPDATE` events to render values live.

---

### Supabase SQL Table Schema (`kiosk_sessions`)

If setting up your own Supabase project, execute this SQL script in the **Supabase SQL Editor**:

```sql
-- 1. Create the kiosk_sessions table
CREATE TABLE IF NOT EXISTS public.kiosk_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  rfid_uid TEXT,
  service_selected TEXT,
  sensor_required TEXT,
  status TEXT DEFAULT 'tap_logged', -- Includes tap_logged, awaiting_profile_completion, awaiting_service_selection, mobile_flow_started, pending_sensor, mobile_sensor_requested, mobile_readings_ready, completed, and cancelled.
  temp_c NUMERIC,
  height_m NUMERIC,
  weight_kg NUMERIC,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 2. Enable Real-Time replication for the table
ALTER PUBLICATION supabase_realtime ADD TABLE public.kiosk_sessions;

-- 3. Row Level Security (RLS) Policy for public kiosk access
ALTER TABLE public.kiosk_sessions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read/insert/update on kiosk_sessions" 
  ON public.kiosk_sessions 
  FOR ALL 
  USING (true) 
  WITH CHECK (true);
```
